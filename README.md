# Keno Game

This project is a fully functional implementation of the popular lottery game, Keno, built entirely programmatically in Java. Rather than using FXML, I manually constructed the JavaFX Scene graph to sustain control over component behavior and layout. I implemented custom event handlers to manage state-based UI changes, enabling interactive button feedback and user-selectable color schemes.

## Technical Highlights
* **Dynamic States:** Developed a system to swap UI styles and background assets at runtime, providing a responsive and customizable user experience.
* **State-Based UI:** Integrated interactive button logic that provides visual feedback to track player selections and winning hits.
* **Randomized Game Logic:** Leveraged Java's randomization library to generate winning numbers for each round.
